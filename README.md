# 2026 高教社杯全国大学生数学建模竞赛 B 题
## 无线电干扰源的快速自动定位与清除

---

## 项目简介

本项目为 2026 年全国大学生数学建模竞赛 B 题的完整代码实现。题目要求在半径为 1800 米的圆形区域内，利用机器狗搭载的测向机与光学清除设备，对未知数量、未知频道的无线电干扰源进行自动搜索、定位与清除。

项目覆盖题目全部四个问题：

- **问题 1**：已知若干检测点及其对某干扰源的示向度，建立交会定位模型，计算定位区域凸多边形的直径，并判断以该直径为直径的圆能否覆盖整个定位区域。
- **问题 2**：已知某全向干扰源在一个检测点处测得的示向度，设计第二个检测点的选择策略，使交会定位效果较好，并给出第二个检测点的候选区域。
- **问题 3**：目标区域内均为全向干扰源，总数 10～16 个但具体个数未知。机器狗从原点出发，初始频道为 1，需自动搜索、定位并清除所有干扰源，使完成任务的时间尽可能短。
- **问题 4**：目标区域内既有全向干扰源，又有定向干扰源，总数仍为 10～16 个。定向源的个数及定向方向均未知，其他条件与问题 3 相同，需要设计检测与清除策略并通过模拟器验证。

代码包含问题 1～4 的求解程序、离线模拟测试脚本以及结果输出。在线程序通过 HTTP+JSON 接口与官方模拟器通信，支持演练与正式测试。

## 问题与算法概述

### 问题 1：交会定位区域直径与覆盖判断

对应文件：`src/problem1.py`

- 随机生成干扰源真实位置与若干检测点。
- 根据测得的示向度（含 ±1° 误差）构建每个检测点的角域约束。
- 将角域约束转化为半平面，两两求交并筛选出位于目标圆域内的顶点，得到凸多边形定位区域。
- 计算凸多边形直径（区域内任意两点最大距离）。
- 判断以该直径为直径的圆是否覆盖整个定位区域。
- 输出中间数据、顶点、直径及覆盖结论。

### 问题 2：第二个检测点选择策略

提供两种方法：

#### 方法 1：网格搜索 + 粒子群优化

对应文件：`src/problem2_method1.py`

- 以第一个检测点 S1、估计源点 P 为基准，在目标区域内网格搜索第二个检测点 S2。
- 评价函数：

  ```text
  fitness = d2 / sin(γ)
  ```

  其中 `d2` 为 S2 到 P 的距离，`γ` 为交会角。
- 使用粒子群优化（PSO）在可行区域内精细搜索，使重叠面积尽量小。
- 绘制结果图，标注 S1、S2、P 及交会角。

#### 方法 2：多分辨率数值积分

对应文件：`src/problem2_method2.py`

- 将扇形区域（±1°）按 1m×1m 网格离散化。
- 对候选区域内的每个 S2 点，数值积分计算其探测光束与扇形区域交集的累加面积。
- 采用多分辨率搜索：
  - 粗筛 50m
  - 细化 5m
  - 细化 1m
- 支持多进程并行加速。
- 输出最优 S2 坐标、累加面积及可视化图。

### 问题 3：全向干扰源搜索定位清除策略

对应文件：`src/problem3.py`

- **覆盖证明**：将 1800m 圆域划分为 792 个小三角形，利用 `no_signal` 结果保守排除候选区域，实现连续区域的覆盖证书。
- **保底锚点**：原点 + 半径 1200m 圆周上每 60° 一个点，共 7 个点，确保全区域覆盖。
- **定位算法**：基于凸多边形可行域，使用最小包围圆评估不确定度。通过横向偏移探测点，逐步缩小包围圆至 ≤19.95m，再执行保证清除。
- **调度策略**：最近邻 + 2-opt 规划任务顺序，优先清除已发现目标，同时顺路扫描未知频道。
- **完成判据**：清除 16 个源，或所有频道均被清除/覆盖证明为不存在，才报告成功。

### 问题 4：全向 + 定向干扰源策略

提供两种方法：

#### 方法 1：分层探测 + 可行域裁剪

对应文件：`src/problem4_method1.py`

- **分层探测点**：生成内层到外层（含竞技场外）的同心圆探测点，覆盖不同距离。
- **可行域裁剪**：对 `direction` 测量，用 ±1.006° 角域裁剪凸多边形，并限制在最大测量距离内。
- **缺失判定**：多方向、多半径、多次 `no_signal` 后判定频道不存在（absent）。
- **清除策略**：当可行域最小包围圆半径 ≤ 19.4m 时执行清除，失败则在邻近点重试。
- **主循环**：优先级清除 → 定位 → 扫描未知/卡住频道。

#### 方法 2：固定锚点环 + 自适应放射扫描

对应文件：`src/problem4_method2.py`

- **固定锚点环**：55 个保底锚点，包括：
  - 原点 1 点
  - 900m 环 6 点
  - 1500m 环 12 点
  - 1800m 环 12 点
  - 1950m 环 18 点
  - 2100m 环 6 点
- **自适应放射扫描**：对疑似定向源，触发 5 半径 × 18 方向 = 90 点的放射扫描，提高捕获概率。
- **类型推断**：根据观测历史与 `no_signal` 分布判断全向/定向，并推断定向方向。
- **定位策略**：结合横向偏移与类型信息，逐步缩小包围圆；支持 `near` 直接清除。
- **收尾处理**：对未定位目标进行放射扫描与保守点测量，尽可能清除。

## 快速开始

### 1. 启动官方模拟器

确保模拟器已运行，并开放 HTTP 接口（默认 `http://127.0.0.1:2026`）。  
在模拟器界面进入问题 3 或问题 4 的演练/正式测试，等待接口就绪。

### 2. 运行各问题脚本

**问题 1：**

```bash
python problem1.py
```

**问题 2（方法 1）：**

```bash
python problem2_method1.py
```

**问题 2（方法 2）：**

```bash
python problem2_method2.py
```

**问题 3（需传入参赛队号）：**

```bash
python problem3.py --robot-id 你的参赛队号
```

**问题 4（方法 1）：**

```bash
python problem4_method1.py --robot-id 你的参赛队号
```

**问题 4（方法 2）：**

```bash
python problem4_method2.py --robot-id 你的参赛队号
```

### 3. 运行离线模拟测试

python test_problem4_method1.py --cases 500 --directional-ratio 0.5

## 注意事项

1. **接口地址**  
   默认 `http://127.0.0.1:2026`，如需修改可在各脚本顶部或通过命令行参数调整。

2. **参赛队号**  
   正式测试必须传入真实队号，否则模拟器会拒绝请求。

3. **时间限制**  
   正式测试窗口 25 分钟，程序运行时间最长 20 分钟。代码中已加入现实时间与虚拟时间预算检查，避免超时。

4. **安全半径**  
   清除时使用 `safe_clear_radius`（略小于 20m）保证成功率。

5. **离线测试**  
   `test_problem4_method1.py` 和 `test_problem4_method2.py` 使用内置模拟器，无需启动官方模拟器，适合快速验证算法。

6. **日志导出**  
   正式测试结束后，请从模拟器导出加密行为日志，并按题目要求放入支撑材料。
